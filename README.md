# To-Do List App

A simple and interactive To-Do List web application built using HTML, CSS, and JavaScript.

This project demonstrates DOM Manipulation and ES6 concepts by allowing users to add, complete, and delete tasks dynamically.

---

## Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Add tasks using Enter key
- Responsive and clean UI

---

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

---

## DOM Concepts Used

- getElementById()
- querySelector()
- createElement()
- addEventListener()
- appendChild()
- innerHTML
- classList.toggle()

---

## ES6 Concepts Used

- let and const
- Arrow Functions
- Template Literals
- Event Handling
